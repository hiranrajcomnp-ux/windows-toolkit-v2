# VASKAR - ULTIMATE WINDOWS TOOLKIT

**Windows IT Administration & Troubleshooting Toolkit**

Developed by Vaskar.

## Features
- System Administration
- Network & Internet Tools
- Windows Repair & Management
- Disk Management
- Security & Defender
- Performance Optimization
- System Information
- Troubleshooting Utilities

## Requirements
- Windows 10 / 11
- Administrator privileges for selected tools
- Git (for contributing)

## Usage
1. Download the `.bat` file.
2. Right-click and select Run as Administrator.
3. Choose a module from the menu.
